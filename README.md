# 基本電學刷題站

技術型高中電機與電子群基本電學的分節練習，共六章、35 節、127 題。[開啟刷題站](https://lrw-crypto.github.io/ee/)

- 可依章節、來源、題型與題數篩選，支援隨機順序。
- 單選與填充即時判分，非選題顯示參考答案供自評。每題附詳解及課本頁碼。
- 錯題可在同一瀏覽器中重做，或下載 A4 PDF，並可選擇是否附答案與詳解。
- 題庫由課本自我評量改編及補充練習組成。課本 PDF 和附錄由章節頁連結。

GitHub Pages 從 `main` 的根目錄提供網站。題庫在 `questions.json`，更新題目時應保留既有題目的 `id`，供作答紀錄使用。填充題的答案欄為依序對應各格的陣列。若題目新增字元，請重新產生 `assets/vendor/ElectricityTC.otf` 的繁體中文子集字型，供 PDF 使用。
